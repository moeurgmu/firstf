# firstf
Custom Node.js implementation of grep for searching the first n lines of a file.

## How the Command works
It's tool that finds a pattern in the first N lines of a file 

## AI Assisted Programing Reflection
I asked AI what certain tools do such as grep and head. Then after implementing code I asked to provide test cases where the code would fail. I asked to see if there were any revisions needed on code after trying to implement my own ways to fix the problems.
